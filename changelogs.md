# 1.1.0

- The full Devicons set is now included: 1,966 full-color icons (1,465 logos and their compact marks).
- Every logo now has a matching folder icon: a folder named after a technology (`supabase`, `redis`, `stripe`…) shows its logo. 1,511 folder names are recognized.
- The plugin is now about 2 MB, since every icon ships with it. Icons still work offline.

# 1.0.3

- English description and screenshots.
- The message shown when Acode has no icon pack support is now in English.

# 1.0.2

- Dark logos with white details (Rust, Next.js, `.env`, Perl, Crystal, Solidity…) are recolored so they stay visible on dark themes.

# 1.0.1

- Fixed the plugin failing to load after a reload or next to another icon pack (`Identifier 'PLUGIN_ID' has already been declared`).
- On Acode versions without icon pack support, the plugin now shows a message instead of crashing.

# 1.0.0

- First release: Devicons file and folder icons for Acode, with 194 file extensions, 236 file names and folder icons for `.github`, `node_modules`, `.vscode`, `docker`, `kubernetes`, `android`…
